# Spam-Detection-using-SVM
Detection System using Support Vector Machines. 
The keywords are ‘cheap’, ‘sale’, ‘needy’, etc. We are going to train our model to detect these kinds of words in the sentences and then we are going to classify it as spam or not spam. 
We will use CountVectorizer
